    Create the machine account¶

    A machine account is this installation's identity in your Backblaze account. Backblaze uses it to group the backup, count the computer against your plan, and show the machine in the restore picker.

    You create it once. Routine backups do not need your Backblaze password again.

    Before you begin¶

    • Have your Backblaze account email and password ready. If the account uses two-factor authentication (2FA), have the current code ready.
    • Decide on a machine name. This is the name you will see in Backblaze and in re-back's restore screen.
    • Do not create a second machine account for an installation that already has one. Reinstalling over a kept state directory will reuse the existing identity.

    re-back does not create a Backblaze account. It attaches this machine to an account you already have.

    Create the account¶

    1. Open the web interface. The first screen is Login, with a Machine account card.
    2. Enter the Backblaze account email and password.
    3. If the account uses 2FA, tick My account uses 2FA and enter the current code.
    4. Click Sign in.
    5. Enter a Machine name, then click Create machine account.

    On success, re-back stores the machine identity in its state directory and the card shows the machine as linked. Your password and 2FA code are used for this request and are not saved by re-back.

    Choosing a machine name¶

    Use a name that tells you what the machine is and where it lives:

    • Good: media-server, office-nas, basement-backup
    • Less useful: linux, server2, test

    The name is a label, not a hostname requirement. It does not have to match the Linux hostname. It can contain spaces, but a short name without spaces is easier to read in a list. The interface accepts up to 120 characters.

    If you leave the name blank, re-back generates a timestamped name such as re-back-20261112_093000. That works, but it is harder to recognize later.

    Renaming later¶

    The Machine account card has a Rename action. Renaming changes the display name only. It does not change the backup's file paths, the machine's identity, or the data already stored.

    If the server cannot confirm the rename immediately, re-back keeps the local name and retries the server update on a later sync. The card will tell you whether the server confirmed it.

    If account creation fails¶

    Check, in this order:

    1. Email, password, and 2FA code. Use the current code; codes expire quickly.
    2. Network access. The machine needs HTTPS access to Backblaze.
    3. Account state. Confirm the account is active and has Computer Backup available.
    4. Existing identity. If the state directory already contains an identity, do not mint another one. Check the Machine account card first.

    Do not repeatedly create machine accounts to work around a login failure. Each successful creation adds another computer to your Backblaze account.

    Protect the identity¶

    The machine identity is stored in the state directory. It is as sensitive as a password: it lets this installation act as this machine. Keep the state directory private (0700 is appropriate), and do not copy it to another machine unless you are deliberately moving the installation.

    A normal restore does not require copying the identity. If this machine is lost, install re-back elsewhere, create a new machine account, sign in on the Restore screen, and select the old machine as the restore source.
